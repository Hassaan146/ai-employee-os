# AI Employee OS - AI Service & Agent Orchestration

This directory contains the AI agent definitions, prompt templates, tool definitions, and RAG pipelines for AI Employee OS.

## Overview
- **AI Employees**: Sales Manager, Support Agent, HR Assistant, Finance Assistant, Executive Assistant, etc.
- **LLM Integrations**: OpenAI GPT, Anthropic Claude, Google Gemini, Whisper (Audio), OCR engines.
- **Agent Tools**: CRM operations, Email drafting/sending, Quotation/Invoice generation, Calendar scheduling.
